### Project Details
#### [Project 1 - TA: Text Analyzers (stemming and tokenization)](https://grape.ics.uci.edu/wiki/public/wiki/cs221-2019-spring-project1)

- Implement a simple tokenizer based on punctuations and white spaces

- Implement a Dynamic-Programming based Word-Break Tokenizer

- Incorporate a Porter stemmer

- Implement a dynamic-programming based Chinese or Japanese tokenizer



#### [Project 2 - II: Inverted index, boolean search](https://grape.ics.uci.edu/wiki/public/wiki/cs221-2019-spring-project2)

In this project, a disk-based inverted index and the search operations have been implemented.

- Implement LSM-like disk-based inverted index that supports insertions only.

- Implement merge of disk segments.

- Implement keyword search, boolean AND search, and boolean OR search.

- Implement deletions.


#### [Project 3 - PI: Positional index, phrase search, compression](https://grape.ics.uci.edu/wiki/public/wiki/cs221-2019-spring-project3)

In this project, a disk-based positional index and phrase search operations have been implemented.

- Implement an LSM-based positional index.

- Implement phrase search.

- Implement compression.

- Implement deletions.


#### [Project 4 - RA: Ranking](https://grape.ics.uci.edu/wiki/public/wiki/cs221-2019-spring-project4)

In this project, two ranking methods: TF-IDF (Cosine) and PageRank have been implemented.

- Implement TF-IDF ranking.

- Implement PageRank.
